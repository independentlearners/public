Cara membaca dokumentasi API Dart

Bedah anatomi satu entri properti dari halaman FutureOr

📋 Contoh entri yang dimaksud
hashCode → int
The hash code for this object.
no setter inherited
🔍 Arti setiap bagiannya
hashCode — Nama properti.
Ini adalah atribut yang bisa kamu akses dari objek kelas ini. Seperti membaca field pada sebuah objek.
→ int — Tipe kembalian (return type).
Tanda panah (→) menunjukkan "properti ini mengembalikan nilai bertipe...". Jadi saat kamu akses objek.hashCode, hasilnya adalah sebuah int.
"The hash code for this object." — Deskripsi fungsi.
Penjelasan singkat apa kegunaan properti ini. Hash code adalah angka unik yang merepresentasikan objek, dipakai saat objek disimpan di Map, Set, dll.
no setter + inherited — Badge status.
Inilah bagian yang paling sering membingungkan. Penjelasannya ada di bawah.
🏷️ Arti badge "no setter" dan "inherited"
no setter
Properti ini hanya bisa dibaca (read-only).

Kamu tidak bisa melakukan:
obj.hashCode = 99; ❌

Tapi bisa:
print(obj.hashCode); ✅
inherited
Properti ini bukan didefinisikan di sini.

Properti ini diwarisi dari kelas induk, yaitu kelas Object (semua kelas Dart mewarisi dari Object).

FutureOr tidak mendefinisikan ulang hashCode — ia hanya mewarisinya.
💡 Ilustrasi dalam kode Dart
// Misalkan kamu punya Future sebagai FutureOr
FutureOr<int> nilai = 42;

// ✅ Bisa: hashCode adalah getter (readable)
print(nilai.hashCode); // misal: 42

// ❌ Error: tidak ada setter, tidak bisa di-assign
nilai.hashCode = 99; // ← compile error!

// "inherited" artinya hashCode berasal dari Object
// Semua class Dart mewarisi Object, termasuk FutureOr
📐 Ringkasan pola umum di dokumentasi Dart API
Badge Artinya
no setter Hanya bisa dibaca. Tidak bisa di-assign nilai baru.
inherited Diwarisi dari kelas induk (biasanya Object), bukan didefinisikan di kelas ini.
read-only Sama dengan no setter — properti tidak bisa diubah.
override Kelas ini mendefinisikan ulang properti/method dari induknya.
