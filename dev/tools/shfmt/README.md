# shfmt

**Jenis:** formatter shell  
**Implementasi utama:** Go  
**Peran:** memformat Bash/sh secara konsisten.

## Contoh
```bash
shfmt script.sh
shfmt -w script.sh
shfmt -d script.sh
```

## Modifikasi
Siapkan Git, Go toolchain, pemahaman Bash/sh, parser, AST, formatting rules, dan testing.
