# yazi

**Jenis:** file manager TUI  
**Implementasi utama:** Rust  
**Peran:** navigasi dan operasi filesystem keyboard-driven dari terminal.

## Contoh
```bash
yazi
```

## Modifikasi
Untuk source development, siapkan Git, Rust toolchain, dan pemahaman TUI/filesystem. Lua berguna untuk konfigurasi dan extension yang menggunakan mekanisme Lua upstream.
