# lazygit

**Jenis:** Git TUI  
**Implementasi utama:** Go  
**Peran:** workflow staging, commit, branch, diff, rebase, dan operasi Git lain dari terminal.

## Contoh
```bash
lazygit
```

## Modifikasi
Siapkan Git, Go toolchain, make, pemahaman Git internals/CLI, dan konsep terminal UI. Repository upstream juga menyediakan lingkungan development berbasis Go.
