# bat

**Jenis:** file viewer CLI dengan syntax highlighting  
**Implementasi utama:** Rust  
**Peran:** membaca source code dengan highlighting, nomor baris, dan integrasi Git.

## Contoh
```bash
bat README.md
bat src/main.rs
bat --paging=never file.txt
```

## Modifikasi
Siapkan Git, Rust toolchain, Cargo, pemahaman terminal output, syntax highlighting, dan konfigurasi theme/syntax.
