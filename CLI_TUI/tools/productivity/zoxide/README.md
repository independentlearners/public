# zoxide

**Jenis:** directory jumper shell  
**Implementasi utama:** Rust  
**Peran:** navigasi cepat ke direktori yang sering digunakan.

## Contoh
```bash
z project
z foo bar
zi project
```

## Modifikasi
Siapkan Git, Rust toolchain, pemahaman filesystem/path, ranking/search, serta integrasi Bash/Zsh.
