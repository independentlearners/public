# fd

**Jenis:** pencarian file/direktori CLI  
**Implementasi utama:** Rust  
**Peran:** alternatif yang sederhana dan cepat untuk `find`.

## Contoh
```bash
fd README
fd '\\.dart$'
fd -t d projects
```

## Modifikasi
Siapkan Git, Rust toolchain, Cargo, serta pemahaman filesystem, path, traversal direktori, dan testing.
