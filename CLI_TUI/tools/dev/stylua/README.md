# StyLua

**Jenis:** formatter Lua  
**Implementasi utama:** Rust  
**Peran:** formatting deterministik untuk Lua 5.1–5.4, LuaJIT, dan varian yang didukung upstream.

## Contoh
```bash
stylua .
stylua --check .
```

## Modifikasi
Siapkan Git, Rust toolchain, Cargo, pemahaman Lua, parser/AST, dan desain formatter. Untuk integrasi Neovim, pahami editor integration.
