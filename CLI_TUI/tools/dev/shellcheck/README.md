# ShellCheck

**Jenis:** static analyzer shell script  
**Implementasi utama:** Haskell  
**Peran:** menemukan bug, quoting error, portability issue, dan pola shell yang berisiko.

## Contoh
```bash
shellcheck script.sh
shellcheck -s bash script.sh
```

## Modifikasi
Siapkan Git, Haskell toolchain, pemahaman Bash/sh, parser shell, static analysis, dan testing rule.
