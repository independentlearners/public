# Project Status

## Tujuan

Repository ini adalah ruang publik untuk materi pembelajaran dan referensi berbahasa Indonesia. Struktur harus dapat dipahami dan digunakan tanpa bergantung pada workspace privat `independentlearners/file`.

## Hasil Kinerja Terakhir

- Ruang personal `saya/` telah dikeluarkan dari repository publik.
- Fondasi sistem pembelajaran ditambahkan melalui `LEARNING-SYSTEM.md`.
- Roadmap pengembangan ditambahkan melalui `ROADMAP.md`.
- Audit struktural awal dicatat melalui `AUDIT-001.md`.
- Audit awal telah mengidentifikasi beberapa fungsi berbeda: learning material, reference, index/landing, practice, experiment, project, troubleshooting, dan assessment.
- Pola materi yang sudah matang di dalam repository digunakan sebagai acuan internal, bukan diganti secara serampangan.
- Restrukturisasi materi substantif belum dilakukan secara massal.

## Keputusan Kurasi

1. Repository publik harus mandiri dari repository privat.
2. Konten personal tidak boleh dimasukkan kembali ke repository ini.
3. Tidak semua materi harus menjadi kursus linear.
4. Konsep utama sebaiknya mempunyai canonical source.
5. Dokumen lain sebaiknya merujuk canonical source daripada menduplikasi penjelasan.
6. README diklasifikasikan berdasarkan fungsi sebelum dipindahkan, dipecah, digabung, atau dihapus.
7. Prerequisite harus terlihat ketika sebuah materi membutuhkannya.
8. Link internal merupakan bagian dari knowledge graph dan harus divalidasi setelah perubahan struktur.
9. Audit harus mendahului restrukturisasi besar.
10. Perubahan dilakukan bertahap agar setiap batch dapat diperiksa secara offline.
11. Kelayakan publik ditentukan berdasarkan keterbacaan, konsistensi, navigasi, validitas link, kemandirian materi, dan kemudahan pemeliharaan.
