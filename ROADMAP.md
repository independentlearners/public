# Roadmap Repository Pembelajaran

Roadmap ini menjadi urutan pengembangan `independentlearners/public`. Ia bukan daftar semua materi yang harus segera dibuat; ia adalah urutan kerja untuk membangun sistem pembelajaran yang koheren.

## Phase 0 — Foundation

- [x] Menetapkan `public` sebagai peta/kurikulum publik.
- [x] Mendokumentasikan peran submodule.
- [x] Menetapkan model pembelajaran.
- [ ] Audit seluruh tautan internal.
- [ ] Audit struktur direktori.
- [ ] Menetapkan metadata materi secara bertahap.
- [ ] Menambahkan pemeriksaan otomatis untuk kualitas repository.

## Phase 1 — Struktur Pengetahuan

- [ ] Memetakan domain utama.
- [ ] Menentukan prerequisite setiap jalur.
- [ ] Mengidentifikasi materi yang terputus atau melompat terlalu jauh.
- [ ] Mengidentifikasi duplikasi.
- [ ] Menentukan canonical location untuk konsep yang muncul di beberapa tempat.

## Phase 2 — Jalur Fundamental

- [ ] CLI dan terminal.
- [ ] Sistem operasi.
- [ ] Dasar pemrograman.
- [ ] Struktur data dan algoritma.
- [ ] Git dan workflow pengembangan.
- [ ] Networking fundamental.

## Phase 3 — Bahasa dan Ekosistem

- [ ] Dart.
- [ ] Lua.
- [ ] Bahasa lain sesuai kebutuhan roadmap.
- [ ] Hubungan antara konsep umum dan implementasi spesifik bahasa.

## Phase 4 — Pengembangan Perangkat Lunak

- [ ] Software engineering.
- [ ] Testing.
- [ ] Debugging.
- [ ] Architecture dan design.
- [ ] Package/dependency management.
- [ ] Documentation.

## Phase 5 — Domain Lanjutan

- [ ] Cybersecurity.
- [ ] Systems programming.
- [ ] Networking lanjutan.
- [ ] AI/ML.
- [ ] Compiler dan language tooling.
- [ ] Domain lain setelah prerequisite tersedia.

## Phase 6 — Project dan Assessment

- [ ] Project bertingkat berdasarkan prerequisite.
- [ ] Assessment untuk jalur utama.
- [ ] Kriteria penyelesaian yang dapat diamati.
- [ ] Review berkala terhadap materi yang sudah ditandai selesai.

## Phase 7 — Quality Automation

- [ ] Markdown linting.
- [ ] Broken-link checking.
- [ ] Validasi metadata.
- [ ] Pemeriksaan struktur direktori.
- [ ] Pemeriksaan referensi submodule.
- [ ] Ringkasan perubahan dan status kurasi otomatis.

## Aturan Pengembangan Roadmap

Roadmap boleh berubah setelah audit repository. Penambahan topik baru tidak boleh otomatis menggeser prerequisite yang sudah terbukti benar. Jika urutan diubah, alasannya harus dapat ditelusuri dari hubungan konsep, kebutuhan praktis, atau hasil evaluasi materi.
